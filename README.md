# SnapStudy

## AI-Powered Personalized Study Assistant

SnapStudy is an AI-powered study assistant designed to help students learn more effectively through personalized study support.

### Features

- Personalized study packs
- Concept explanations
- Practice questions and MCQs
- Targeted practice based on learning needs
- Interactive AI-assisted learning experience

### Tech Stack

- TypeScript
- React
- Vite
- AI-powered features

### Purpose

SnapStudy aims to make learning more personalized, accessible, and engaging by helping students understand concepts and practice according to their needs.

### Project

Built as a student-focused AI learning solution for the Snapdragon-powered PC ecosystem.
